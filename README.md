# Веб-калькулятор СМО

Весь сайт находится в `dist/`. Откройте `dist/index.html` двойным щелчком. Работает без Python, установки пакетов, интернета и серверной части. На другой компьютер передавайте **всю папку dist**, включая assets, JS и CSS, либо архив SMO_website.zip.
Разработчики: Сомов, Иванов
Для размещения на своём хостинге загрузите содержимое dist в корень сайта. Для локальной раздачи по HTTP: `python3 -m http.server 8765 --directory dist` и адрес http://localhost:8765. Облачная публикация Sites по умолчанию приватная; автономные файлы не требуют входа в аккаунт.

## Функции

Дополнительный флаг «Задать ρ вместо интервала поступления» включает ввод ρ,C,m,t₀. Интервал вычисляется как tвх=t₀/(ρ·C), без промежуточного округления, и показывается отдельной строкой. Исходный ввод tвх остаётся основным по умолчанию; его значение сохраняется при переключении. Режим действует на обе методики и весь прогон. ρ>1 разрешено; это предложенная нагрузка, а не фактическое использование аппаратов U. В дробном режиме заданное ρ относится к среднему C; отдельные целые конфигурации смеси имеют свои нагрузки.

- Вкладки M/M/c/m, G/G/c/m и теория.
- Четыре общих входа, C* и a; запятая или точка; крупный шрифт.
- Полный набор стационарных показателей M/M и вероятности состояний.
- Сравнение обеих методик есть **на обеих вкладках анализа**: Pотк, Pотк*, Δ, относительное расхождение в процентах. Кнопка «Сравнить модели» открывает вкладку G/G с теми же входами.
- Прогон буфера по текущему набору Python-программы: 1, 3, 5, 10, 20, 25, 50. В engine.js массив buffers можно изменить, например заменить 3 на 2.
- На графике две линии; если браузер не поддерживает Canvas, остаётся таблица с теми же числами.
- Копирование в табличном формате: при недоступном автоматическом копировании текст выделяется для Ctrl+C/Cmd+C.
- Теория: отрисованные формулы, исходная запись LaTeX и пояснения без CDN.
- Дробные C,m: смесь соседних целых конфигураций, как в Python-программе.
- При rho=1 автоматически применяется исправленная формула −C/[C(C−1)/2−C(m/a+C*+1)], совпадающая с пределом основной. Недопустимые вероятности не обрезаются, а отмечаются (!).

## Совместимость

Код написан в синтаксисе ES5, без модулей, fetch, Promise, стрелочных функций, CSS Grid/Flexbox и обязательных внешних библиотек. Ориентир — IE9+ в стандартном режиме и браузеры с поддержкой ES5. Это целевой уровень, а не заявление о проверке на реальном IE. Нужен включённый JavaScript; без него доступна теория. Старые браузеры могут не пройти современную HTTPS-аутентификацию облачного хостинга: для них используйте автономную папку или собственный HTTP-сервер.

Опорные спецификации: [ECMAScript 5.1](https://262.ecma-international.org/5.1/), [Canvas API](https://developer.mozilla.org/en-US/docs/Web/API/Canvas_API). Canvas не является обязательным для расчётов.

G/G — заданная приближённая методика C*,a, а не точное решение произвольной G/G-системы. Процент в сравнении — расхождение относительно базы M/M, а не измеренная ошибка относительно реальной системы. Единицы интервалов произвольны, но должны совпадать; времена на выходе в тех же единицах.

## Изменения

`dist/engine.js` — расчётное ядро, `dist/app.js` — интерфейс и список выходных показателей в функции metrics; `dist/style.css` — оформление. `dist/index.html` содержит теорию и исходные формулы. Никакой сборки для обновления не требуется.

Проверки: `node test.js`. При переносе формул дополнительно сверено 360 наборов параметров с Python-версией, включая rho=1, окрестность единицы и дробные входы. В Safari через MCP проверены таблица сравнения, переключение вкладок, прогон, график и формулы теории. Реальный старый браузер отдельно не проверен.
